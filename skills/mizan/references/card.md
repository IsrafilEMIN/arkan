# Mizan card

One page per standing model. Fill it before engaging with new material. Log entries accumulate under it.

```
MODEL:        <name> v<n>                      date:
CLAIM:        <one sentence: what this model says>
BECAUSE:      <the mechanism: why it works; without it you have a correlation, not a model>
DEFAULT:      <the boring explanation this model must beat>
WHO BENEFITS: <who gains if the claim is true; GRIP letters if relevant>
RIVALS:       <other explanations held at the same time>

PREDICTIONS (written before looking):
  1. If the claim holds, <observable> by <date or event count>     status: open / confirmed / broken
  2. ...
KILL CONDITION: <the observation that breaks the model outright>
CUE QUESTION:   <the one question to carry while reading or observing>
CONFIDENCE:     unlikely / even / likely / strongly likely   (never certain)

LOG
[date]
Guess:       <default / rival A / rival B ...>
Setup:       <what was checked>
Expected:    <per rival>
Actual:      <raw result>
Now believe: <what moved, and how>
```

When a prediction breaks: retire the model, or write v<n+1> with the change named. Keep the old card.
