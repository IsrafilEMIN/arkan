### Worktree and simulator cleanup

1. Snapshot and audit. Record `df -h /`, then run `scripts/worktree-audit.sh [-b <pr-base-ref>] [repo-path]` (`principle-build-the-lever`). Without `-b` it checks `MERGED` against `origin/HEAD`, so pass `-b origin/<branch>` when PRs target another branch. It reads paths from `git worktree list`, never hand-typed, since a hand-typed `myrepo-worktrees/x` misses one a harness or another agent created somewhere else, such as under `/private/tmp` (`principle-encode-lessons-in-structure`). It classifies each worktree by size, age, merge state, uncommitted work, PR state, and the newest omp chat that touched it, then suggests a bucket. `LAST_CHAT` reads only omp's transcripts, so under another harness it reads `-` and step 3 does that check by hand. The transcript scan is slow, so background it.
2. The bucket is advice, not permission. The pinned and active chats are the real artifact (`principle-prove-it-works`). Get that set from the user or the harness's session list and cross-check every candidate. The lever has marked `safe` a worktree the user had pinned, so the pinned set wins.
3. Verify usage before deleting. For every `verify-recent-chat` row, or anything you doubt, fan subagents out to read the transcripts (where they live: the table in the `recall` skill) and report whether the chat is pinned or ongoing and which worktrees it touches (`principle-guard-the-context-window`, transcripts are bulk). A pinned chat spawns arena and repro trees into sibling worktrees via background subagents, and those are in use even when their names never show in the session list. Match each subagent's model to the job, per **Subagents** in `SKILL.md`.
4. Pause on irreversible loss. `wip:N` is N tracked uncommitted edits, and `scratch:N` is N untracked files. No branch keeps either, so removing them cannot be undone: show the diff or name the files, and get a decision first. Per **autonomy** in `SKILL.md`, a worktree that is clean, merged and not in use proceeds, because its branch still holds every commit. `wip`, `scratch` and in-use pause.
5. Prune the confirmed set. Per path, `git worktree remove <path>`. Add `--force` only for a worktree whose uncommitted or untracked files the person agreed to drop in step 4. If the dir survives on ignored build artifacts, `rm -rf` it, then `git worktree prune`. Branch refs survive, so no commits are lost. Confirm with `df -h /` and re-list.
6. Simulators and other reclaimers. Simulators are usually the next-biggest win. `xcrun simctl --set testing delete all` (XCTestDevices clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` then `runtime delete <id>` for old runtimes. More when needed: Xcode `DerivedData` and `iOS DeviceSupport`, `~/Library/Application Support/Cursor` (`state.vscdb.backup`, and `snapshots/roots/<root>` where a `<root>` named for a folder you opened as a workspace balloons), package caches (pnpm, uv, brew, yarn). Clear only caches the user has not said to keep.

This is the one playbook that deletes user state with no code review to catch a slip, so the gates above are the review.

**Reply:** `df -h /` before and after with space reclaimed, the worktrees pruned, and a one-line reason for each held back (in-use by which chat, or uncommitted work).
